# 臻晨健康实例说明

## 首页主张

> 让健康常相伴

## 页面内容

- Hero：让健康常相伴
- 品牌定位：报告有人讲，后续有人跟
- 三张卡片：把情况看清、把话说明白、把后续接上
- 五项内容：专业判断、报告说明、服务安排、留下记录、继续跟进
- 结尾：往后的事，我们接着跟

- 4 张场景图

- 第一轮不使用视频

- 保留 Three.js、WebGL、摄影机、滚动和动画
