# 文案计划 v2

## 原则

- 品牌主句只保留：**让健康常相伴**
- 句子短，口语自然，不解释口号。
- 主页要有内容，但不堆概念，不写无法核实的承诺、排名或数字。
- 文案围绕一次服务如何开始、怎么进行、之后如何接续。

## 页面结构

### 首屏

- 主句：让健康常相伴
- 四个节点：专业判断 / 报告说明 / 服务安排 / 继续跟进

### 第一章：臻晨

- 标题：先把一家人的情况看清
- 正文：每个人来时，带着的问题都不一样。先把既往情况、生活习惯和这次最关心的事放在一起，检查才有方向。
- 补充：护士陪着走流程；需要判断的地方，由医生当面讲。
- 链接：看看服务怎么接着走
- 四步：预约沟通 / 到店评估 / 医生说明 / 后续跟进

### 第二章：服务

- 标题：一次检查，接着一整套服务。
- 导语：该做什么、怎么看结果、后面怎么安排，都有人接着。
- 三张卡：先评估，再检查 / 到店有人陪着 / 把后续接上
- 长期说明：照顾的是一家人，也是一段很长的时间。
- 正文：孩子在长大，父母的身体在变化，长辈也有自己的节奏。每个人关心的事不同，安排自然不能只用一张固定清单。
- 补充：臻晨把资料、检查、医生建议和后续记录放在一起。下次再来，不用从头说起。

### 第三章：相伴

- 标题：不同的问题，找对人来看。
- 导语：需要进一步关注时，再进入对应的专项评估。
- 十项关注：代谢健康、心脑血管、免疫与肿瘤、脑健康、肺健康、消化健康、肌骨与运动、生殖健康、口腔健康、眼健康。

### 收尾与页脚

- 收尾主句：往后的事，我们接着跟。
- 收尾正文：一家人的健康会变，我们把每一次检查、说明和安排接起来。
- 页脚品牌句：把一次检查，接成一家人的长期健康服务。
- 页脚栏目：服务 / 关注 / 相伴

## 不使用

- 不写“领先、唯一、保证、治愈、最先进”。
- 不把数字系统写成服务主角。
- 不增加长段品牌自述。
- 不保留 Kage、京都、寺院、夜游等原项目文字。
- 没有真实去向的外部链接不做按钮。

## 验收

- 页面有完整的首页信息层次，不再只有口号和几张图。
- 所有可见句子能在桌面和手机宽度下正常换行。
- 文案能与到店、评估、检查、说明、跟进和家庭陪伴的图片逐一对应。
- 口号不被额外解释。
