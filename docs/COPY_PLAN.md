# 文案计划 v3

## 原则

- 品牌主句只保留：**让健康常相伴**
- 参考用户提供的《服务手册》和臻晨相关宣传资料，优先沿用原句，只做页面长度所需的微调。
- 句子短，口语自然，不解释口号。
- 主页要有内容，但不堆概念，不写无法核实的承诺、排名或数字。
- 文案围绕一次服务如何开始、怎么进行、之后如何接续。

## 页面结构

### 首屏

- 主句：让健康常相伴
- 四个节点：舒心服务 / 专业检测 / 全程陪同 / 长期相伴

### 第一章：臻晨

- 标题：以用户为中心
- 正文：以质量为核心，以“五心”服务为标准。
- 补充：从预约、接待到检查和说明，每一步都有人陪着走。
- 链接：看看服务怎么接着走
- 四步：预约沟通 / 到店评估 / 医生说明 / 后续跟进
- 四步说明：先说清最关心的事 / 全程导医导检，流程更顺心 / 一份科学的检测报告，当面讲清 / 检查之后，继续关注健康变化。
- 四个步骤直接在主页补一句说明，不另开内容。

### 第二章：服务

- 标题：专属·个性·全流程
- 导语：信任，源自一份科学的检测报告。
- 三张卡：先评估，再检查 / 到店有人陪着 / 把后续接上
- 长期说明：舒心、顺心、放心、安心、贴心。
- 正文：提供舒适的健检环境，让用户感到舒心。待用户为家人，让用户感到顺心。
- 补充：为用户提供精准的健检报告，让用户感到放心；严守职业操守，让每一次沟通都安心、贴心。
- 三张服务卡点击后打开同一个悬浮详情框，补充“怎么开始、怎么进行、怎么接续”。

### 第三章：相伴

- 标题：健康中心检测体系
- 导语：围绕不同年龄和人生阶段，安排专属、个性的健康评估。
- 十项关注：代谢健康、心脑血管、免疫与肿瘤、脑健康、肺健康、消化健康、肌骨与运动、生殖健康、口腔健康、眼健康。
- 十项说明沿用手册中的短句：掌握健康活力枢纽，不给健康添堵；超早期捕捉微小病变，筑牢心脑血管防线；掌控人体“国防军”，预警潜在风险；筑牢脑部防线，让健康无须“脑”；守护健康肺，呼吸更顺畅；呵护消化系统动力，全面激活肠胃动力；精准评估骨骼健康，焕活生命运动力；深度检测生殖系统，动态呵护生殖健康；健康从“齿”开始；让您的“视”界更加“睛”彩。
- 十项关注点击后在主页上方展开悬浮详情，不切换网址，也不离开当前滚动位置。

### 收尾与页脚

- 收尾主句：让健康常相伴。
- 收尾正文：以用户为中心，以质量为核心，让每一次服务都有人接着。
- 页脚品牌句：以用户为中心，以质量为核心。
- 页脚栏目：服务 / 关注 / 相伴
- 页脚中的具体项目复用同一个悬浮详情框；栏目标题和品牌句不做无意义跳转。

## 详情层级

- 首页先给判断所需的短信息，保持 Kage 式连续滚动。
- 需要继续了解的项目使用统一悬浮框，标题、导语、三项要点和一句边界说明构成完整内容。
- 关闭后回到原入口，背景、粒子和立体移动不中断。
- 大幅家庭与医生场景只承担叙事和气氛，不强行添加点击。

## 不使用

- 不写“领先、唯一、保证、治愈、最先进”。
- 不把数字系统写成服务主角。
- 不增加长段品牌自述。
- 不保留 Kage、京都、寺院、夜游等原项目文字。
- 没有真实去向的外部链接不做按钮。

## 验收

- 页面有完整的首页信息层次，不再只有口号和几张图。
- 所有可见句子能在桌面和手机宽度下正常换行。
- 文案能与到店、评估、检查、说明、跟进和家庭陪伴的图片逐一对应。
- 口号不被额外解释。
